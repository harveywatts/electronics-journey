# 03 - Button & Servo

This time I added a button to control the LED, allowing the LED to blink when pressed and dim when released.

I also wired a servo for the first time and tested it by having it rotate 180 degrees back and forth continuously using a simple program.

## Components Used:

- 1 x LED
- 1 x 10KΩ Resistor
- 1 x Push Button
- 1 x Micro Servo 9G SG90
- Breadboard
- Arduino UNO R3
- Jumper Wires

## What I Learned:

- How a push button completes/breaks a circuit when pressed/released
- How to set up and control a micro servo motor (SG90) including moving it to specific angles using code
- How to use an input (button) to control an output
