# 02 - Multiple LEDs

Following my first time successfully blinking an LED, I decided to connect some more to the breadboard watching two, three, then four light up at the same time.

I once again experimented with the code, making them blink in a sequence, fade brightness, and increase and decrease the intervals between blinks.

Again, this was a fairly simple circuit using basic code, but next time I will start by adding a ON/OFF button and some other components.

## Components Used

- 4 x LEDs
- 4 x 220Ω Resistors
- Breadboard
- Arduino UNO R3
- Jumper Wires

## What I learned:

- How to create different LED patterns and effects
- How to control multiple LEDs independently
- Basic understanding of Arduino digital output pins
